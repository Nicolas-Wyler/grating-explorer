Calculation details & aliasing

8 is the default; lower values can miss fine structure.

0 disables this extra filter. Pixel-area averaging remains on.

Pixels below this circular-coherence value are shown gray.

Model. Equal, in-phase scalar spherical waves, U = Σ exp(ikr)/r. No slit-width envelope, material, polarization or multiple scattering is included. The first-to-last source span is (N−1) pitches.

Aliasing. The field is calculated on a wavelength-resolving grid, then integrated over each display pixel. Optional smoothing reduces remaining subpixel patterns. Phase is averaged as a complex unit phasor and unreliable pixels are gray; sampling near true phase singularities cannot be guaranteed.

Source plane. To avoid the singular point-source region and unresolved near-field structure, field maps start at the source-plane cutoff below the grating. The excluded strip is gray.

Angular plot. The annulus is area-weighted. The cosine and cosine-squared curves are applied after summing sources and averaging intensity, rather than as per-source aperture obliquity factors.

Display. Each heatmap is normalized to its own maximum. For linear intensity or amplitude, choose the percentage ceiling; higher values use the maximum color. Intensity and amplitude also support dB (with adjustable range); wrapped phase stays cyclic. The angular curves share one unweighted normalization.

Saved data. Results are kept in this browser on this device and reused when a compatible result is available. Detail regions are saved individually. Browser and Mac-app libraries are separate.
